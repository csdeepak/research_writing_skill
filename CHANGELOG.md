# Changelog

The skill's detailed, versioned changelog (with proposals, evidence and gate results) is
[`skill/changelog.md`](skill/changelog.md). Release summaries:

## 0.4.0 — 2026-09-30: open-source release
- Apache-2.0; governance, security, privacy and contribution documents; CI; issue and PR templates.
- Skill ZIP packaging with validation; single CLI (`tools/rce.py`); repository audit.
- New checks: citation-registry check (C5), per-project language policy, six-state review-finding lifecycle.
- Failure-case archive (`cases/`) and a synthetic example project with planted integrity problems.
- Private-project data and third-party paper texts removed from the public tree (recreated from pinned sources instead).

## 0.3.0 — 2026-09-30
Truth guardrail, evidence-bound figures, reader-comprehension tooling, enforced multi-role workflow with human
checkpoints, model-agnostic runtime. Released as a process upgrade; reader benefit not shown (D-30, D-32).

## 0.2.0 — rejected (2026-09-28)

## 0.1.0 — 2026-09-24
