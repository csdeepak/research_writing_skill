In the authors' words, this paper is meant to report on OpenHands, an open platform for building
and running AI agents that act through code execution, a command line, and a web browser, and to
show that one open, common agent interface can host a single generalist agent that is evaluated,
without per-domain prompt changes, across software-engineering, web-browsing, and
miscellaneous-assistance tasks. A reader should come away understanding what the platform
provides (a small action interface, a reproducible runtime, and harnesses for fifteen
benchmarks), what the generalist agent achieves in each of the three task categories with
specific, sourced numbers, and why those numbers depend heavily on the underlying language model
and on the benchmark subset sizes used.
