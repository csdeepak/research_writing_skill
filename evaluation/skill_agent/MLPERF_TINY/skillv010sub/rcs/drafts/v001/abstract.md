## Abstract

Machine-learning inference is moving onto microcontroller-class hardware that runs on a fraction of a watt, a setting the community calls TinyML. Comparing hardware and software solutions for this setting fairly has been difficult: a general microcontroller benchmark does not run machine-learning workloads, and existing machine-learning inference benchmarks assume far more memory than a microcontroller provides or do not measure energy at all {C009, C010, C011, C012}. This paper presents MLPerf Tiny, an open benchmark suite that pairs four representative tasks -- keyword spotting, visual wake words, image classification, and anomaly detection -- with microcontroller-sized reference implementations and a fixed protocol for measuring accuracy, latency, and energy {C001, C003}. A closed submission division fixes the dataset, model, and accuracy target so that hardware and software stacks can be compared directly, while an open division allows changes anywhere in the pipeline provided they are documented {C004}. In the suite's first submission round, five submissions spanning both divisions and five distinct hardware and software categories -- from a general-purpose microcontroller to a field-programmable gate array trained with quantization-aware learning -- were measured against the reference implementations {C005}. This diversity is consistent with the modular design achieving its goal of accommodating TinyML's hardware and software heterogeneity while keeping results directly comparable {C006}. The evidence for this reading comes from one round with five submissions {L001}.
