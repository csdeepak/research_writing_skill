In the authors' words, this paper is meant to introduce OpenHands, an open platform for building AI agents that act on the world through real software -- writing code, running a shell, and browsing the web -- and to show, through a 15-benchmark evaluation spanning software engineering, web browsing, and other assistance tasks, that a single generalist agent built on the platform, without any benchmark-specific modification to its prompt, performs competitively against agents that were built and tuned for one task category at a time. A reader should come away understanding what the platform provides that earlier, separate agent frameworks did not (a general sandboxed code-and-browser runtime, an extensible tool library, multi-agent delegation, and an integrated evaluation harness, together in one open codebase), what the headline evaluation numbers actually show and do not show (competitive performance on most, not all, of the benchmarks tested, with a comparison that is not a fully controlled ablation of the architecture alone), and what the authors themselves say still needs to improve (multi-modal support, long-file editing, complex-task reliability, and automatic workflow generation).
