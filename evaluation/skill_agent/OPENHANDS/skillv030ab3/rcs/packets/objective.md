In the authors' words, this paper is meant to present OpenHands, an open platform on which AI agents act through code, a shell and a web browser, and to report how its default agents perform on a broad set of benchmarks. The problem is that building and evaluating agents that act through software is hard; the paper asks what infrastructure lets one platform host community-built agents, and how a default generalist agent fares across software, web and assistance tasks without benchmark-specific prompt engineering. A reader should come away understanding what the platform consists of and why the authors built it that way, what was measured and against which reference systems, that the authors describe the results as competitive but not top in every category, and what the authors and this presentation state as limits.
