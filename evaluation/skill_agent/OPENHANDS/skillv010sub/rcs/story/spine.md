# Paper Spine

1. Problem: Software is the most general interface through which an AI agent can act on the world, but building and evaluating agents that use it -- writing code, running it safely, and browsing the web -- has generally meant assembling separate, often single-purpose infrastructure for each new agent or benchmark {C015}.
2. Gap: Prior open agent frameworks tend to supply one piece of this infrastructure at a time rather than the whole set together -- for example, adding code execution without a persistent, stateful session {C019} -- so no single open platform is shown combining safe general-purpose execution, an extensible tool interface, multi-agent composition, and a broad cross-domain evaluation harness.
3. Question: Can one open platform, and one generalist agent built on it with a single fixed prompt, remain competitive across qualitatively different agentic task categories -- software engineering, web browsing, and other tool-use/reasoning tasks -- rather than requiring a bespoke agent per category {C016}?
4. Approach: OpenHands supplies an event-stream interface connecting users, agents, and a Docker-sandboxed runtime that exposes bash, Python, and a browser; an extensible agent-computer-interface tool library; multi-agent delegation; and an evaluation harness spanning 15 benchmarks; on top of this it instantiates a generalist, CodeAct-based agent {C017}.
5. Key finding: Using one fixed system prompt, this generalist agent reaches results competitive with, though rarely the best among, category-specific baselines in software engineering (e.g. 26.0% on SWE-Bench Lite {C001}), web browsing (e.g. 15.5% on WebArena {C004}), and miscellaneous reasoning/tool-use tasks (e.g. 52.0% on GPQA-diamond {C006}) -- and it is the only agent in the comparison evaluated across all three categories at once {C015}.
6. Meaning: This is consistent with a single general action space, run on one shared, safely sandboxed platform, being sufficient for broad and simultaneous competence across domains, rather than each domain requiring its own purpose-built agent {C016}.
7. Main limit: No seed or repeated-run variance is reported for any of these numbers {L001}, the cross-agent comparisons are not backbone-model-controlled {L002}, OpenHands trails the best specialist baseline on several individual benchmarks {L003}, and no ablation isolates which platform component drives the cross-category result {L006}.

## Spine self-checks

- **Tell-a-colleague:** an adjacent ML researcher reading only these seven lines learns what was built, what was tested, what happened, and how far that reaches.
- **Chain test:** Gap->Question: answering Q3 (one platform/one prompt, competitive everywhere) directly narrows the stated gap (no platform shown combining the full infrastructure set). Finding->Meaning: the meaning ("a single general action space ... is sufficient for broad competence") follows from the finding without extra evidence, and is hedged ("consistent with") rather than asserted as proof.
- **Honesty test:** line 7's four limits are specific to line 5/6's finding (variance, model confound, non-top-performance, missing ablation), not generic boilerplate.
- **One-contribution test:** line 5 names one organizing finding -- simultaneous cross-category competitiveness of a single fixed-prompt generalist agent. The per-benchmark numbers are supporting results, not co-equal contributions.
