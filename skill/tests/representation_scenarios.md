# Representation decision regression scenarios

Use these for future behavioral review after editing representation guidance. They are expected
decisions, not evidence that a model passed. Record actual outputs separately. For a fair
comparison, freeze the same source files, task and audience assumptions for both versions.

| Scenario | Expected decision |
|---|---|
| Architecture memory exists, but no logs/results | Provisional traced diagram; blocked result plots; no invented learning curve |
| Two methods have paired measurements and uncertainty | Consider a paired/difference or interval plot; do not force prose solely because there are two estimates |
| Aggregate improves while a meaningful subgroup worsens | Keep the subgroup boundary beside the main comparison; no selective relegation |
| Old design includes a module absent from inspected implementation | Show actual version; separate the proposed module; preserve supersession provenance |
| Metrics have different units/ranges | Aligned separate scales or table; no arbitrary normalized combined score or misleading stack |
| Qualitative study with divergent excerpts | Theme/evidence structure and divergent cases; no invented prevalence or statistical interval |
| Null result with wide uncertainty | Report estimate and uncertainty; do not turn non-significance into equivalence |
| Tight page limit and long failed-run logs | Condense logs and retain source; keep any limitation affecting a claim in main text |
| Appropriate heatmap exceeds bundled renderer/schema capabilities | True type in card; external scientific tool; explicit integration/check gap; no false V-gate pass |
| Exemplar has many elaborate panels | Borrow only patterns serving the new reader task; no fixed quota or copied success narrative |
| Theory paper has no sample size or experimental Results | Assumptions/propositions/proofs; empirical fields not applicable with reason; no fake data to satisfy templates |
| Venue's font/caption requirements differ from an example | Follow verified venue profile and inspect physical final size; do not equate SVG pixels with print points |
