# Getting help

- **How do I…?** Read `docs/guides/INSTALL.md` and `docs/architecture.md` first. For questions, use GitHub
  **Discussions** if they are enabled, otherwise open an issue with the *Question* label.
- **Something produced an unsupported claim, a wrong number or a misleading figure:** open an *Evidence integrity*
  issue. These are the reports that improve RCE most.
- **Security problem:** do not open an issue; see `SECURITY.md`.

This is a volunteer-maintained research project with no guaranteed response time. When you report, include the RCE
version, the model and provider, and a minimal reproduction **without confidential research data**.
