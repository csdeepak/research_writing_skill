## Rules for this registry
1. Add a source only after checking it against a live index or publisher page. Record the date.
2. A preprint stays **PP** until you find a peer-reviewed version. Then record both.
3. Cite a source only for what it actually established. The "Why it is used" column is the
   scope of permitted use. Using a source outside that scope requires re-reading it.
4. This registry supports the *design documents*. The skill's runtime source registry for a
   user's paper is a separate artifact (`source_registry.json`; see `skill/citation_rules.md`).
